# 🎮 Text Adventure Web Game

## 🧩 About
This is a small web-based text adventure game built using Java Spring Boot.  
The idea is simple: the player reads a situation and chooses what to do next. Based on that choice, the story continues in a different direction.

Every choice matters, and different paths can lead to different endings.

---

## ⚙️ How it Works
The project is divided into two parts:
- **Backend (Spring Boot):** Handles the story logic and manages what happens after each choice
- **Frontend (HTML/CSS/JS):** Displays the story and buttons for user interaction

When a user clicks an option, a request is sent to the backend, and the next part of the story is returned and shown on the screen.

---

## ✨ Features
- Interactive story flow
- Multiple decision paths
- Simple and clean interface
- Fast response using Spring Boot APIs
- Easy to modify and extend story content
